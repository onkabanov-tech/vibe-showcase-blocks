# Правила вёрстки

1. Верстаем обычными HTML, CSS и JS, без сборщиков и фреймворков. Так же, как сделан черновой фронт.
2. Один экран прототипа — одна страница в папке `web`.
3. Все обращения к серверу идут через `web/js/api.js`. Внутри страниц запросов быть не должно.
4. Цвета, шрифты и размеры берём только из `web/tokens.css`. Новых значений не добавляем.
5. Папку `server` не трогаем. Если для экрана не хватает данных, сначала говорим об этом мне.
6. Папку «Прототип» не меняем и не переименовываем, она только образец.
7. Ошибку от API показываем клиенту текстом на экране, а не только в консоли.
8. Экраны мастера и администратора пока не верстаем.

Перед вёрсткой нового экрана — сначала смотрим его строку в [docs/ui-map.md](./ui-map.md).
