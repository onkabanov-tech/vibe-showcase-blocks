## Цель

Добавить Hero-секцию и привести все секции лендинга к визуальному стилю референса (Aviasales): яркий синий фон-баннер, оранжевый акцент CTA, белые карточки со скруглениями и мягкими тенями, светло-серый фон страницы, плотная сетка, шрифт без засечек.

## Что будет сделано

### 1. Дизайн-токены (src/styles.css)
- `--primary` → синий Aviasales (~oklch(0.55 0.22 258)), `--primary-foreground` белый.
- Новый токен `--accent-cta` / `--accent-cta-foreground` — оранжевый (~oklch(0.68 0.19 45)) для кнопок «Найти/Обсудить проект», зарегистрировать в `@theme inline`.
- `--background` → чуть холодный светло-серый; `--card` белый; `--secondary` — светло-голубой для тегов/чипов.
- `--radius` увеличить до ~1rem (крупные скругления как в референсе).
- Тени: токен `--shadow-card` (мягкая, низкоконтрастная).
- Тёмная тема остаётся согласованной (без визуального рассинхрона).

### 2. Новая Hero-секция (`src/components/Hero.tsx`)
Структура по референсу — крупный синий блок во всю ширину:
```text
[ синий фон ]
  H1: сильный заголовок (напр. «Запускаю продукты с ИИ за недели, а не месяцы»)
  подзаголовок 1–2 строки
  [ оранжевая кнопка CTA ]  [ вторичная кнопка-ссылка ]
  строка мини-статов: 3 показателя в белых «пилюлях»
```
- Мобильно: текст по левому краю, кнопки на всю ширину, вертикальный стек.
- Заголовок `text-4xl md:text-6xl`, семантика — единственный `<h1>` на странице.

### 3. Обновление существующих секций (только визуал, тексты/логика не меняются)
- **WhatIDo**: белые карточки на светлом фоне, иконка в светло-синем квадрате со скруглением, блок «Результат» — светло-голубая плашка вместо разделителя.
- **HowItWorks**: номера шагов синим, кружки-иконки — синяя заливка с белой иконкой, линия таймлайна светло-синяя.
- **FeaturedProjects**: карточки с крупным радиусом и мягкой тенью, теги — синие чипы (`bg-secondary text-primary`), лёгкий hover-подъём.
- Чередование фонов секций: белый / светло-серый, чтобы читались как отдельные блоки.

### 4. Сборка страницы (`src/routes/index.tsx`)
Порядок: Hero → WhatIDo → FeaturedProjects → HowItWorks. Обновить `head()`: title/description под лендинг целиком (сейчас они про «Избранные проекты»), сохранить og/twitter теги.
